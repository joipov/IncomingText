# Incoming Text

For World of Warcraft: Forever (Classic Plus).

**Damage, healing, and status, each in its own list.** Misses stay on the damage list. `+Combat` / `-Combat`, and an aura removed from you, stay on the status list. Each list has its own place and look.

**Damage**, **Healing**, and **Status** are separate settings pages. Each has enable, lock, font, size, crit size, opacity, fade time, lines, align, grow, and its own colors. The damage page has **Show misses**. The status page has **Show combat** and **Show dispels**. **Show combat** prints `+Combat` on entering combat and `-Combat` on leaving. **Show dispels** prints the aura name, such as `Polymorph dispelled`. The main page has the same **Lock position**, font, size, opacity, fade time, lines, align, and grow rows. Changing one of those writes it onto all three lists. Fonts from other addons appear when the shared media library is installed. Turn **Lock position** off to drag that list's area or either edge, then right-click it to lock. The minimap button is on by default and opens settings.

`/it` opens settings. So does the addon compartment. `/it test` shows sample lines.
